# Mike Jattu Portfolio

Welcome to my personal portfolio website! This site showcases my projects, skills, and experience as a developer.

## Features

- Project gallery with descriptions and links
- About me section
- Contact information

## Technologies Used

- HTML5, CSS3, JavaScript
- React.js
- Node.js (for backend)
- Responsive design

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mikejattu/mikejattu_portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
