# The Beginning

When I first started my Computer Science degree at the University of Alberta, I wasn't sure which path I wanted to take. Web development? Systems programming? Game development? The options seemed endless.

## The Turning Point

Everything changed when I took my first machine learning course. The idea that computers could *learn* from data and make predictions fascinated me. I remember spending hours tweaking neural network parameters, watching accuracy metrics improve with each iteration.

## Real-World Application

The real breakthrough came when I began applying those ideas in research and municipal data science. Suddenly, the algorithms I'd learned in class were solving actual problems:

- **Oil-sands level estimation**: Using DeepLabV3 segmentation and contour post-processing to monitor dump-hopper levels
- **Traffic analytics**: Building an open-source vehicle-detection pipeline for continuous model training and deployment

## What I've Learned

1. **Theory matters, but practice matters more** - You can read all the papers you want, but nothing beats hands-on experience
2. **Domain knowledge is crucial** - Understanding the problem space is just as important as knowing the algorithms
3. **Iteration is key** - My first model rarely works perfectly. The magic happens in the refinement
